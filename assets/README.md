# The Eye artwork

`the-eye-logo.webp` is a web-sized export of the original red-eye artwork approved for this series. It is not the later hand-drawn SVG substitute. No new image was generated or redrawn for this revision.

The original 1254 x 1254 PNG, named `The Eye logo.png`, is retained with the facilitator's reference materials. This display export is 320 x 320 pixels, resized with Lanczos resampling, composited on white for legibility on light or dark pages, and encoded as WebP (quality 80). The illustration and lettering come from the approved original. Use the original for larger print or projection exports rather than enlarging this small file.

The Eye is an independent feature for the discussion series. The artwork is not an official Project Jupyter logo or a statement of endorsement. Reuse the approved artwork rather than generating a fresh logo each week.
